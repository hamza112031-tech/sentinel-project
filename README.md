# sentinel-project
A secure system administration toolkit built with Bash scripting. The project provides a menu-driven interface for user authentication, system monitoring, backup management, task tracking, remote server monitoring, and file sharing.

## Features
- Secure Authentication System
- System Resource Monitor
- Backup Utility
- Admin Task Manager
- Remote Uptime Monitor
- Temporary File Server

## Requirements
- Linux Environment
- Bash Shell
- Python3

## How to Run
chmod +x *.sh
bash sentinel.sh
